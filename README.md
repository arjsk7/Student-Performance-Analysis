# Student-Performance-Analysis
Hi 


This is a Student Performance analysis CLI tool I have created that class teachers can use to:


1. See the distribution of the total marks of students in class to identify the highest or lowest performing students in their class. They can either input the details of each students on the program or use the excel sheet in the folder to enter the details and also have a copy of the same, the excel sheet can also be updated in time and the graph in the program will be updated respectively as well when you run the same. (using a Bar Graph)

2. See the share of each subject in the total marks of a student, this can help identify the strengths and weaknesses of the student and see what subjects each student need more help with. (using a Pie Chart)

3. See the trend of a student's total marks over multiple terms so they can assess the student's performance in those terms to see if they are improving or not and if they need more help. (using a Line Chart)
